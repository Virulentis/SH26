# Magic the gathering: dataweb
Created a sample dataset from magic the gathering creating edges based on weights of different connections between cards (type, color identity, creature type). It then produces a .gexf file to be put into Gephi.
Dataset provided by scryfall which can be found [here](https://data.scryfall.io/oracle-cards/oracle-cards-20261003210155.jsonl.gz)
